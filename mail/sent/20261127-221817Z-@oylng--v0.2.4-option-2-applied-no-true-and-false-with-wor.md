1. Quotes never count for a scalar's type (your option 2). `3`, `"3"`, `'3'` and `|-` before `3`

4. The emitter writes null as `null` everywhere, not as no value. That was the user's lean, not yours.
   It reads back under `!null` and `{!|: [!null, ...]}`. The emitter refuses a string that the type at
   its place reads as something else, since quoting no longer helps (section 13).

5. `!true` and `!false` are new standard types, and `!bool` is `{!|: [!true, !false]}`.
   `!true`, `!false` and `!null` each take one list of words, which replaces the standard spelling,
   as in `{!|: [!true(yes|on), !false(no|off)]}` and `!null(~|null|)` (section 4.1). The rules:
   - Words are split at `|`. An empty word is the empty text, and it is only allowed beside another
     word. A word can't hold a space, `|`, `/`, `(` or `)`.
   - A word that appears twice in one list refuses the schema.
   - The emitter writes the first word, or `""` if the first word is empty.
   - A word in both `!true` and `!false` of one union isn't refused: the first alternative wins.
   - `!bool` takes no words.
   - A table name still wins over the new standard names (section 8).

6. Patterns are now for `!int`, `!bigint`, `!float` and `!decimal` only, so `!null(/~/)` is refused.
   Because the parentheses now hold words, `!null(0..1)` loads, with the word `0..1`.
